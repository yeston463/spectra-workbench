# 里程碑、任务与验收

每个阶段都交付源码、启动方式、实际验证记录和剩余问题。以下性能数值是待测工程目标，不是当前软件实测值。任务 ID 与 `04_BACKLOG.json` 对应。

## P0 · 工程与目标环境

| ID | 任务 | 验收标准 |
|---|---|---|
| P0-01 | 检查开发目录、建仓库与文档结构 | 不覆盖无关文件；保留已有改动；README 有运行与开发入口 |
| P0-02 | 解析并锁定 UI/GDAL/Rasterio/science 环境 | 提交精确版本、构建与 win-64 环境锁；独立进程能分别导入引擎 |
| P0-03 | 实现 doctor 和小型 fixture 生成 | GTiff 往返、坐标转换、CLI、资源目录和驱动分别报告；无 HDF4 仍可打开 GUI |
| P0-04 | 建立最小检查与自动化流水线 | Ruff、核心类型检查、小型 pytest 在新环境可运行；原生集成检查独立分组 |
| P0-05 | 提前验证 Windows runtime 打包可行性 | 最小 Qt 窗口和两个引擎在另一目录启动；发现重定位或 DLL 问题写 ADR 并解决 |

退出条件：实际版本与环境可以复建，GUI 与引擎互不依赖全局安装；不是只生成 requirements 文件。

### 性能目标与测量约定

参考验收配置：Windows 11 x64、至少 4 核 CPU、16 GiB RAM、本地 NVMe、1920×1080 显示。实际硬件、数据与驱动必须记录；低于参考配置可单列报告，不伪造达标。

| 指标 | 目标 | 条件 |
|---|---|---|
| 启动 | 冷启动到可交互 ≤10 秒，热启动 ≤5 秒 | 运行时已安装，能力扫描可后台；本地离线 |
| 首屏 | 有概览的本地 tiled 影像，首屏目标 ≤2 秒 | 固定 1–4 GiB 参考样本，缓存状态记录；无概览另测 |
| 界面响应 | 长任务时事件循环延迟 p95 ≤100 ms，单次长停顿单列 | 60 秒操作脚本+计时器；不含 OS 外部阻塞 |
| 协作取消 | 点击后通常 ≤2 秒进入终态 | 指定支持取消的处理；无回调工具另列强制结束宽限 |
| 内存 | 固定视图反复平移后趋稳，缓存不超过配置预算 | 连续 10 分钟；同时报告 worker 内存 |
| 大逻辑数据 | 读取逻辑大小超过内存的数据时不整幅加载 | 可用稀疏合成影像测内存，但不能据此宣称真实磁盘吞吐性能 |

这些目标由 Qoder 实测后更新。任何不达标项需有瓶颈定位、改进或明确限制，不能仅降低指标隐藏问题。

### v1.0 判定

P0–P10 的必需平台任务通过；目标版本全部公开能力已对账且有明确入口或依赖/原生专有缺口说明；常规已支持处理具备可执行面板；核心数据与算法验收通过；安装包在干净 Windows 验证。这里的 v1.0 是核心平台发布，不表示缺少外部依赖的全部专题也已完成。

若尚有上游核心算法无入口、GUI 只能显示静态图、工作流无法执行、脚本只接受包装函数、安装包依赖开发机环境，均不能判定完成。外部服务、专有驱动与未取得真实课程数据的验收逐项列出条件，不混入已通过结果。

执行账本中 `release_requirement=core` 的任务属于核心发布门槛；`conditional` 任务仍属于总体路线，不能被删除或冒充完成。所有核心任务完成且有条件项未完时，只能宣布核心版本满足发布门槛，同时列出未完条件项，不能宣布整个开发方案全部实现。

## 统一验收样例库

| 编号 | 数据与操作 | 核对内容 |
|---|---|---|
| A01 | 单波段 ramp、常量、多波段已知值 | 读写、波段顺序、dtype、元数据、原始像元 |
| A02 | 非零 NoData、合法 0、NaN、alpha 与 mask | 透明区、统计、运算、重采样和导出语义 |
| A03 | north-up 与旋转 affine、不同 CRS | 像元中心/角点、逆变换、叠加、查询与 ROI |
| A04 | 相邻和重叠的合成 tiles | 镶嵌优先级、网格对齐、VRT 源引用、堆叠 |
| A05 | 简单带孔多边形、空几何、多部件图层 | 栅格化、polygonize、字段/编码、空间过滤 |
| A06 | 解析平面 DEM | 坡度/坡向单位、边界、NoData；与解析结果比较 |
| A07 | 已知频率正弦/条纹、奇偶尺寸与复数数组 | FFT 峰值、往返误差、掩膜坐标和虚部 |
| A08 | 已知线性相关多波段矩阵 | PCA 协方差、特征空间和完整重建；特征向量符号不作错误判据 |
| A09 | Red/NIR 已知小数组和分地类 NDVI | 指数、分母 0、端元、分位数算法、FVC 及无效区 |
| A10 | 已知仿射变换的参考/待配准影像 | GCP 拟合、独立检查点、插值误差和差值 |
| A11 | time/depth/y/x 多维数组 | 维度坐标、切片索引、scale/offset 与导出 |
| A12 | 中文/空格/特殊字符路径与无扩展名 ENVI | 引擎启动、参数传递、头文件配对和 sidecar 提交 |
| A13 | HTTP Range 测试服务与可控超时 | 远程范围读取、取消、重试、凭据脱敏 |
| A14 | 提交时崩溃、输出无权限、磁盘错误注入 | 终态、残缺成果、重试和恢复 |
| A15 | 新环境与打包后环境运行同一任务 | 版本、驱动、空间参考与数值一致性 |

浮点误差门槛按算法、dtype 与样本尺度制定。例如小型 float64 FFT/PCA 往返可先设相对误差目标 1e-10，再用实际实现和独立参考确认；float32 不照搬此阈值。对随机算法固定随机种子，记录算法参数。

## 进度与时间管理

不承诺无基线测量的固定日历工期。P0/P1 后根据环境、渲染和适配器实测难度评估后续工作量。主路径：环境 → 任务闭环 → 能力表单 → 显示与通用处理 → 广度/专题 → 工作流/扩展 → 审计发布。

每轮保存 `docs/progress/STATUS.md`，内容为：当前里程碑、已完成任务 ID、真实运行/检查命令及结果、已知失败与缺数据、下一项任务、关键 ADR。JSON 任务状态与文字进度保持一致。未验证只标 implemented 或 awaiting_data，不标 done。
