# 交付检查表

此清单用于 Qoder 自检和用户验收。勾选必须有实际证据，任务定义本身不构成证据。

## 架构

- [ ] Python + PySide6 桌面入口可启动；GUI 无原生地理引擎导入依赖。
- [ ] GDAL/Rasterio 在独立进程、明确环境中执行；各自版本可查询。
- [ ] GUI、批处理、工作流、历史重跑复用统一任务与 provider。
- [ ] 协议能处理分包、乱码、普通日志、错误、进程重启和超时。
- [ ] 活动计算期间取消可达；子进程清理有 Windows 实测。
- [ ] 长任务与瓦片/查询队列分离，不能互相长期饿死。

## 能力范围

- [ ] 固定上游版本基准，保留来源和哈希。
- [ ] GDAL 新旧命令、公开 API、Rasterio API/rio 和驱动均有独立清单。
- [ ] 私有 API、枚举、方法、别名不混算成处理算法数。
- [ ] 适合参数化的已支持处理能通过表单执行。
- [ ] 复杂 API 能在对应引擎的真实 Python 会话中调用。
- [ ] 未装驱动、缺服务、未接入、未验收的状态准确；统计分母不被悄悄缩减。
- [ ] 高级参数、驱动选项和配置未被 UI 静默丢弃。
- [ ] 增删插件、升级引擎后能比较能力差异。

## 数据与显示

- [ ] 原值/物理值/显示值分开；零值、NoData、NaN、mask 和 alpha 清楚。
- [ ] 大影像只按需读窗口，内存和磁盘缓存有上限。
- [ ] 旧瓦片不会覆盖新视图；QImage/QPixmap 生命周期正确。
- [ ] CRS、轴顺序、像元中心/角点、旋转 affine 与重采样经验证。
- [ ] 无 CRS、GCP/RPC/geolocation、多维切片有明确支持/缺口状态。
- [ ] 图层关闭后数据集句柄释放；文件可在 Windows 重命名/删除。
- [ ] 原始源文件不会因单纯查看而被静默改写。

## 处理与复现

- [ ] 输出会重新打开核对数值、空间参考、dtype 和 mask，非只检查存在。
- [ ] 多文件成果有清单和失败恢复；无假成功图层。
- [ ] FFT/PCA/指数/FVC/GCP 等采用独立公式或不变量验证。
- [ ] 分类训练/验证划分和误差定义明确；不同默认设置不强行比较逐位一致。
- [ ] 外部大气校正、复杂融合等没有用简化算法冒充同名方法。
- [ ] 工作流真实执行，支持失败传播、恢复、缓存失效和跨引擎物化。
- [ ] 项目保存、迁移、数据重定位与崩溃恢复通过。
- [ ] 处理历史记录实际引擎/版本/输入/参数/关键配置。

## 发布

- [ ] 精确环境锁和构建脚本已提交。
- [ ] onedir 与 engine runtime 能搬到另一中文/空格目录。
- [ ] 干净 Windows、离线、无全局 Python 可启动并处理数据。
- [ ] Qt 插件、GDAL/PROJ 数据和驱动依赖齐全。
- [ ] 凭据未进入项目、日志、例子或诊断包。
- [ ] 安装、升级、卸载保留用户项目和数据。
- [ ] 测试、性能、能力覆盖和未完成清单与实际交付一致。
- [ ] 第三方声明、组件清单、构建与恢复说明齐备。

## 整体不能判定完成的典型情形

- 窗口能打开，但输入、运算和导出用的是 mock 数据。
- 有全量名称列表，但点击后只有“功能待开发”。
- 脚本编辑器存在，但无法直接导入所需原生 API。
- 有进度条和取消按钮，实际计算不能取消。
- 同一界面叠加不同 CRS 数据时仅按像素位置摆放。
- 所有 NaN/NoData 被变成零，统计和科学结果失真。
- 只测开发机，安装包依赖开发目录、系统 PATH 或全局 Python。
- 把缺少课程数据、专有驱动或外部服务的未验项写成全部通过。
