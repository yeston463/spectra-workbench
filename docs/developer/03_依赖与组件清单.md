# Spectra Workbench 依赖与组件版本清单

本文档归档 Spectra Workbench v1.0 所锁定的上游基准依赖版本、自包含发布包的四套运行时架构构成、GDAL 驱动支持矩阵以及第三方开源软件合规许可证清单。

---

| 核心组件 | 锁定版本 | 运行位置 | 主要用途 | 许可证 |
|---|---|---|---|---|
| **Python** | 3.12.8 / 3.11.9 | 全局多引擎 | 解释器基础运行环境（64 位 Windows） | PSF License |
| **PySide6** | 6.9.3 | `app/` (UI) | Qt 6.9.3 官方 Python 绑定，提供跨平台桌面 GUI 与图形视图 | LGPLv3 |
| **PyQtGraph** | 0.13.7 | `app/` (UI) | 高性能科学绘图与高帧率二维像元渲染画布 | MIT |
| **GDAL / OGR / OSR** | 3.13.3 | `runtimes/gdal/` | 地理栅格/矢量读写、严密重投影、空间切片与地形分析 | MIT / X License |
| **PROJ** | 9.5.1 | `runtimes/gdal/` | 地球空间坐标参考系统与大地水准面投影变换引擎（含 `proj.db`） | MIT |

## 2. 发布包运行时架构矩阵 (`dist/SpectraWorkbench/`)

Spectra Workbench onedir 发布包采用多运行时解耦物理布局，避免单一环境加载过多依赖产生冲突：

```text
dist/SpectraWorkbench/
├── SpectraWorkbench.exe             # 原生 PE GUI 启动器 (Win32，无黑框)
├── SpectraWorkbench-console.exe     # 原生 PE 控制台启动器 (CLI 转发与诊断)
├── SpectraWorkbench.bat             # 批处理双保险启动器
├── uninstall.exe                    # 原生 PE 快速卸载器 (带用户工程资产保全)
├── uninstall.bat                    # 批处理卸载器
├── manifest.json                    # 发布包全局架构元数据与校验哈希
├── app/                             # 主程序与 UI 运行时
│   ├── python.exe                   # 独立 Python 解释器
│   ├── Lib/                         # 标准库与依赖包 (PySide6 6.9.3, pyqtgraph, pydantic)
│   ├── DLLs/                        # Python 标准 C 扩展
│   ├── qt.conf                      # Qt 相对路径资源重定向配置
│   └── src/spectra_workbench/       # 应用程序主代码
├── runtimes/
│   ├── gdal/                        # 独立 GDAL 引擎运行时
│   │   ├── python.exe               # 独立 Python 解释器
│   │   ├── bin/                     # 162 个原生二进制与 CLI (gdalinfo, gdalwarp, ogr2ogr 等)
│   │   ├── share/gdal/              # 161 项 CRS 规范与投影参数集 (含 epsg.wkt)
│   │   ├── share/proj/              # PROJ 数据库 (proj.db, 空间参考字典)
│   │   ├── Lib/sitecustomize.py     # 自动注册 DLL 目录与 PROJ 寻址
│   │   └── Lib/site-packages/osgeo/ # GDAL/OGR 官方原生驱动绑定
│   ├── rasterio/                    # 独立 Rasterio 引擎运行时
│   │   ├── python.exe               # 独立 Python 解释器
│   │   ├── rio.exe / Scripts/       # 独立 rio 命令行工具
│   │   └── Lib/site-packages/rasterio/ # Rasterio 1.5.2 核心与动态库
│   └── science/                     # 独立科学计算运行时
│       ├── python.exe               # 独立 Python 解释器
│       └── Lib/site-packages/       # NumPy 2.5.4, SciPy 1.18.1 等数学计算库
└── resources/                       # 字体、矢量图标、预置色彩映射表
```

## 3. GDAL 驱动支持矩阵

经 `src/spectra_workbench/app/doctor.py` 自动化探测，发布包内置的 GDAL 3.13.3 运行时共支持 **205 种** 空间驱动，核心常用格式如下：

### 常用栅格格式支持

| 驱动代号 | 格式全名 | 访问模式 | 特性与适用 |
|---|---|---|---|
| **GTiff** | GeoTIFF | Read / Write / CreateCopy | 行业标准栅格格式，支持 LZW/DEFLATE 压缩与大文件 BigTIFF |
| **COG** | Cloud Optimized GeoTIFF | CreateCopy / Read | 针对 HTTP Range 请求优化的云原生栅格格式 |
| **ENVI** | ENVI .hdr Labelled Raster | Read / Write / CreateCopy | 经典高光谱格式，支持带头文件 `.hdr` 的连续二进制多波段存储 |
| **netCDF** | Network Common Data Format | Read / Write | 气象海洋科学多维数据集，支持 CF 空间元数据规约 |
| **PNG** | Portable Network Graphics | Read / CreateCopy | 8位/16位无损压缩网格，支持 Alpha 透明通道 |
| **JPEG** | JPEG JFIF | Read / CreateCopy | 摄影与正射影像有损压缩展示 |
| **BMP** | MS Windows Device Independent Bitmap | Read / Write / CreateCopy | 基础位图格式 |
| **VRT** | Virtual Raster | Read / Write | GDAL 虚拟栅格，支持免重采样拼接与波段多图层动态映射 |

### 常用矢量格式支持

| 驱动代号 | 格式全名 | 访问模式 | 特性与适用 |
|---|---|---|---|
| **GPKG** | OGC GeoPackage | Read / Write | 现代单文件 SQLite 容器，支持多图层空间几何与属性索引 |
| **ESRI Shapefile**| ESRI Shapefile | Read / Write | 经典矢量多文件包（.shp/.shx/.dbf/.prj），完整支持 GBK 编码 |
| **GeoJSON** | GeoJSON Text | Read / Write | 结构化 Web 空间要素交换格式，原生 UTF-8 |
| **FlatGeobuf** | FlatGeobuf Binary | Read / Write | 高性能流式二进制矢量格式，空间索引读取极快 |

3. **GDAL / OGR / OSR** 采用 **MIT / X License**，允许自由集成与商业/非商业分发；
